# PDF Cad

เว็บแอปสำหรับแจ้งแก้ไขแบบก่อสร้างบนไฟล์ PDF — วาด markup แบบ CAD (เส้น ผนัง วงกลม เส้นโค้ง เฟอร์นิเจอร์ สัญลักษณ์แบบ) แล้วบันทึกเป็น PDF ได้ 2 แบบ

- **PDF เส้นดำ** — แบบที่แก้แล้ว ใช้งานได้เลย ไม่มีเลข ไม่มีหน้าเพิ่ม ไม่มีไฟล์แนบ
- **PDF แจ้งแก้ (สี)** — ทุกสี + เลขลำดับ + หน้าสรุป + หน้าข้อมูลสำหรับ AI/โปรแกรมนำไปแก้ต่อ

ทำงานในเบราว์เซอร์ทั้งหมด ไฟล์ไม่ถูกส่งขึ้นเซิร์ฟเวอร์

**พัฒนาโดย 4rch1.k3ng นันทวัฒน์ ส.**
